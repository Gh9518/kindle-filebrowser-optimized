# Kindle 的 filebrowser 优化（网页文件管理器 2）/ Kindle filebrowser optimization (Web File Browser 2)

> 当前版本：**2.0.3**。版本规则：功能更新递增小版本号；多次小修小改累积后也可递增一次小版本号（2.0 → 2.0.1 → 2.0.2 → 2.0.3 …）。中文标题「网页文件管理器 2」固定不变，不随版本号变动。

基于 [filebrowser](https://github.com/filebrowser/filebrowser) 的 Kindle（KUAL）网页文件管理器插件，可在手机、平板或电脑的浏览器中管理 Kindle 里的文件。本插件的原始方案与思路源自书伴（BookFere）文章 [《File Browser：便捷地管理 Kindle 中的文件》](https://bookfere.com/post/823.html)。核心程序已内置打包（v2.63.23，armv7），开箱即用，并支持在线更新。

> File Browser 已于 2026-09-01 归档，v2.63.23 为最后一个版本，后续不再有更新。

## 功能 / Features

- **启动 / 关闭**：默认监听 `http://<本机IP>:80`；运行时保持屏幕常亮，**仅退出或自动退出时才关闭网络**（锁屏不会断网）。执行完后返回 Kindle 桌面。
- **自动退出（两套独立机制，谁先触发谁关闭）**：
  - **闲置退出**（默认开启）：连续 **1 分钟 80 端口无任何传输**即自动退出，适合"传完文件就走"，不用记着关、也不白白挂机耗电。
  - **定时退出**：`从不 / 03分 / 05分 / 10分`（默认 05分），启动后固定时间退出，适合长时间挂机传输时兜底。一次点击即生效。
  - 菜单末尾的「取消闲置退出」**只关闭闲置检测，定时退出档位照常生效**；再点「恢复闲置退出」即可开回来。
- **本机IP**：菜单内直接显示当前 IP；点击可在屏幕显示（eips 位置 12,3）。
- **更新核心程序**：先联网校验再选择更新，下载带实时进度。
- **飞行模式**：按「启动时」的网络状态还原（启动时为飞行模式则退出时重开）。
- **中英文菜单**：默认中文（不判断系统语言）；菜单最后一项显示「将要切换到的目标语言」——中文菜单显示 `English`、英文菜单显示 `中文`，点开即可选 中文 / English。也可手动用 `LANG` 文件切换。

## 安装 / Install

1. 越狱并安装 KUAL / MRPI。
2. 将本文件夹（保持名为 `filebrowser`）放入 Kindle 的 `extensions/` 目录。
3. 打开 KUAL，即可看到「网页文件管理器 2」菜单。

## 使用 / Usage

- 菜单默认以**中文**显示；如需切换语言，点菜单最后一项（中文时显示 `English`、英文时显示 `中文`），再选 **中文** 或 **English** 即可。
- 进入「网页文件管理器 2」→「启动」，屏幕显示本机 IP。
- 电脑浏览器访问 `http://<显示的IP>:80`，即可管理 `/mnt/us`（Kindle 根目录）下的文件。
- 「关闭」停止服务并（按需）还原飞行模式后返回桌面。

## 自动退出 / Auto-exit

| | 闲置退出 | 定时退出 |
|---|---|---|
| 触发条件 | 连续 1 分钟无传输 | 启动后固定 N 分钟 |
| 菜单项 | 取消闲置退出 / 恢复闲置退出 | 从不 / 03分 / 05分 / 10分 |
| 默认 | 开启 | 05分 |
| 状态文件 | `IDLE`（`off`=已取消） | `AUTOCLOSE`（`0`=从不） |

两者**互不影响**：点「取消闲置退出」后，已设置的 03/05/10 分定时退出依旧会在到点时关闭服务；反之改定时档位也不会动闲置开关。若想完全不自动退出，把定时退出设为「从不」并点「取消闲置退出」。

## 语言切换 / Language

- **默认中文**：插件默认以中文显示，不判断 Kindle 系统语言，无需任何配置即可直接使用。
- **菜单内切换**：点菜单最后一项——当前为中文时显示 `English`、为英文时显示 `中文`（即"将要切换到的目标语言"本身的名字），进入后选 **中文** 或 **English** 即可。
- **手动切换（等效）**：在插件根目录（即 `extensions/filebrowser/`，与 `start.sh` 同级）新建名为 `LANG` 的文件，内容只写 `en`（英文）或 `zh`（中文）一行；保存后重启 KUAL 生效。删除该文件即恢复默认中文。
- 说明：`LANG` 文件仅含 `en` 或 `zh` 一行文本；eips 屏上状态提示因字体不含中文字形，始终为英文。

## 菜单结构 / Menu

```
网页文件管理器 2
├ 启动（飞行模式下先提示「打开网络并继续 / 暂不启动」）
├ 关闭（按需还原飞行模式，返回桌面）
├ 自动退出：05分 → 从不 / 03分 / 05分 / 10分 / 取消闲置退出
│              （前 4 项 = 定时退出，末项 = 闲置退出开关，互不影响）
├ 更新核心程序（先校验，再选择 确认更新 / 暂不更新）
├ 本机IP: 192.168.x.x   ← 直接显示，点击可在屏幕显示 IP（eips 12,3）
└ English / 中文         ← 菜单最后一项：中文菜单显示 English，英文菜单显示 中文；点开可选 中文 / English
```

## 脚本结构 / Structure

所有脚本共享 `lib.sh`，避免重复代码：

| 脚本 | 职责 / Role |
|------|------|
| `lib.sh` | 公共函数库（IP 获取、屏幕状态、语言判断等） |
| `genmenu.sh` | 按设置/更新状态生成 `menu.json`（含中英文与版本号） |
| `start.sh` | 启动（飞行模式处理、常亮、开端口、显示 IP、脱离终端后台启动核心程序与自动退出守护） |
| `stop.sh` | 关闭：结束服务与自动退出守护，按需还原飞行模式，返回桌面 |
| `ip.sh` | 屏幕显示本机 IP（位置见 `lib.sh` 的 `IP_ROW`/`IP_COL`） |
| `timeout.sh` | 设置定时退出时间（先重建菜单，确保一次点击即生效） |
| `autoclose.sh` | 定时退出计时器：到点调用 `stop.sh` |
| `idle.sh` | 闲置退出守护：连续 1 分钟无传输即调用 `stop.sh`（可被菜单暂停） |
| `idletoggle.sh` | 切换「取消 / 恢复闲置退出」开关（写 `IDLE` 并刷新菜单） |
| `setlang.sh` | 设置界面语言（写 `LANG` 并刷新菜单），供语言选择菜单调用 |
| `update.sh` | `check`=校验更新；`do`=下载安装 |

## 说明 / Notes

- **核心程序启动方式**：filebrowser v2.63.23 是「无子命令直接启动服务器」，`start.sh` 用
  `./filebrowser --noauth -a 0.0.0.0 -p 80 -r /mnt/us -d ./filebrowser.db`（**不带 `serve`**）。
  早期版本误加了 `serve` 子命令，会报 `unknown command "serve"` 立即退出、80 端口无人监听，
  导致"启动成功（显示了 IP）却 `ERR_CONNECTION_REFUSED`"——已修复。
- 端口 80 已通过 `iptables` 放行；后台以 `setsid` 完全脱离终端并将日志写入 `/tmp/filebrowser.log`，避免联网/断线时崩溃。启动前会先结束残留进程（释放 80 端口与数据库写锁），并清理上一轮的自动退出守护以免定时器叠加。
- 启动后会轮询 `/proc/net/tcp` 与 `/proc/net/tcp6` 等待端口监听（约 15s，`-a 0.0.0.0` 时监听落在 IPv6 双栈表）。
- **闲置退出如何判定「传输」**：读 `iptables` 中 `--dport 80` 规则的累计计数，只统计访问本服务的流量（Kindle 后台联网不计入，实测静置时计数恒定不变、一次页面请求即增长）；若该规则不可用，退化为统计非 `lo` 网卡字节并加 4KB 阈值过滤噪声。连续 1 分钟无变化即关闭，采样间隔 10 秒，误差约 ±10 秒。
- `eips` 帧缓冲字体不含中文字形，故屏上状态提示统一用英文；中文仅保留在 KUAL 菜单 UI。
- `AUTOCLOSE` 保存定时退出秒数（`0`=从不，菜单提供 从不/03/05/10 四档）；`IDLE` 保存闲置退出开关（`off`=已取消，删除或写 `on` 即恢复）；旧值仍按分钟换算显示。`WIFI_STATE` 为运行时临时状态，请勿手动编辑。
- 修改 IP 显示位置：编辑 `lib.sh` 顶部的 `IP_ROW` / `IP_COL`（默认 12 / 3）。
- 升级核心版本后启动失败：可删除 `filebrowser.db` 重新「启动」，filebrowser 会自动重建配置。
- **无法访问排查**：浏览器务必用 `http://<IP>:80`（不要写 `https://`）；filebrowser 启动需数秒，请稍候再试。若仍连不上，启动后屏幕会显示 `Err: …`（取自 `/tmp/filebrowser.log`），常见原因：① 本题 Kindle 架构与 `filebrowser`(armv7) 不符导致无法执行；② 防火墙/网络不在同一网段；③ 端口被其它程序占用。
