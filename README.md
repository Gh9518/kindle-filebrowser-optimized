# Kindle 的 filebrowser 优化（网页文件管理器 2）/ Kindle filebrowser optimization (Web File Browser 2)

> 当前版本：**2.0.8**。版本规则：功能更新递增小版本号；多次小修小改累积后也可递增一次小版本号（2.0 → 2.0.1 → … → 2.0.8 …）。中文标题「网页文件管理器 2」固定不变，不随版本号变动。

基于 [filebrowser](https://github.com/filebrowser/filebrowser) 的 Kindle（KUAL）网页文件管理器插件，可在手机、平板或电脑的浏览器中管理 Kindle 里的文件。本插件的原始方案与思路源自书伴（BookFere）文章 [《File Browser：便捷地管理 Kindle 中的文件》](https://bookfere.com/post/823.html)。核心程序已内置打包（v2.63.23，armv7），开箱即用，并支持在线更新。

> File Browser 已于 2026-09-01 归档，v2.63.23 为最后一个版本，后续不再有更新。

## 功能 / Features

- **启动 / 关闭**：**启动约 2 秒即可在屏幕看到 IP**；默认监听 `http://<本机IP>:80`；运行时保持屏幕常亮，**仅退出或自动退出时才关闭网络**（锁屏不会断网）。执行完后返回 Kindle 桌面。
- **自动退出（单一机制：不传输才计时）**：连续一段时间 **80 端口无任何传输**即自动退出，比"启动后固定时间退出"更贴近实际使用 —— 传文件时一直在用就不会被踢出，传完离开、静置到点才自动关闭省电。档位 `从不 / 1分 / 3分 / 5分`（默认 1分）；**「从不」= 关闭自动退出功能**。一次点击即生效，守护每轮重读设置，改档位无需重启服务；守护每 3 秒检测一次传输与 IP。
- **无网络超时**：启动后若一直拿不到 IP，连续 **2 分钟无网络**即自动退出（与「关闭」共用出口，按需还原飞行模式）；一旦联网，无网计时清零。
- **本机IP**：菜单内直接显示当前 IP；点击可在屏幕显示（eips 位置 12,3）。**启动后若尚未联网，屏幕会提示「Waiting for network…」，联网后最多 3 秒即自动刷新为真实 IP**；若连续 2 分钟仍无网络则自动退出，无需重启程序。
- **更新核心程序**：先联网校验再选择更新，下载带实时进度。
- **飞行模式**：按「启动时」的网络状态还原（启动时为飞行模式则退出时重开）。**手动「关闭」与「自动退出」共用同一套退出流程**，都会据此还原网络。
- **中英文菜单**：默认中文（不判断系统语言）；菜单最后一项显示「将要切换到的目标语言」——中文菜单显示 `English`、英文菜单显示 `中文`，点开即可选 中文 / English。也可手动用 `LANG` 文件切换。

## 安装 / Install

1. 越狱并安装 KUAL / MRPI。
2. 将本文件夹（保持名为 `filebrowser`）放入 Kindle 的 `extensions/` 目录。
3. 打开 KUAL，即可看到「网页文件管理器 2」菜单。

## 使用 / Usage

- 菜单默认以**中文**显示；如需切换语言，点菜单最后一项（中文时显示 `English`、英文时显示 `中文`），再选 **中文** 或 **English** 即可。
- 进入「网页文件管理器 2」→「启动」，屏幕显示本机 IP。
- 电脑浏览器访问 `http://<显示的IP>:80`，即可管理 `/mnt/us`（Kindle 根目录）下的文件。
- 「关闭」停止服务并（按需）还原飞行模式后返回桌面。

## 自动退出 / Auto-exit

自动退出有**两条互补的判定路径**，都走同一个出口 `stop.sh`：① 已联网时连续无传输达到档位时长；② 未联网时连续 2 分钟拿不到 IP。档位只控制第 ① 条。

| 档位 | 含义 |
|---|---|
| 从不 | **关闭自动退出功能**：守护空转待命，不判定、不退出（相当于旧版的「取消闲置退出」） |
| 1分 / 3分 / 5分 | 连续 1 / 3 / 5 分钟 80 端口无传输即自动退出 |

- 状态文件 `AUTOCLOSE` 保存秒数：`0`=从不，`60/180/300`=1/3/5 分。菜单里点档位即写入，一次点击生效。
- **「传输」如何判定**：读 `iptables` 中 `--dport 80` 规则的累计计数，只统计访问本服务的流量（Kindle 后台联网、以及飞行模式开关 WiFi 都不计入；实测静置时计数恒定不变、一次页面请求即增长）。规则不可用时退化为统计非 `lo` 网卡字节并加约 1.2KB 阈值过滤噪声（按采样窗口等比缩放）。**采样间隔 3 秒，误差约 ±3 秒**；有任意传输就把计时清零。
- **与飞行模式状态机的结合**：自动退出触发时，守护调用与手动「关闭」相同的 `stop.sh`，因此会一并结束服务、关闭屏幕常亮、按启动时记录的 `WIFI_STATE` 决定是否重新开启飞行模式、返回桌面。也就是说「自动退出」和「手动关闭」还原网络的行为完全一致。
- **先无网后联网也能正常工作**：空闲计时只统计「已联网」阶段 —— 启动时尚无网络时，守护只提示等待、清空计时、不判定，不会把「无网等待期」误算成空闲而到点自动退出；网络一通，计时从零开始，IP 屏显最多 3 秒即刷新为真实地址。
- **无网络超时（v2.0.7）**：连续 **2 分钟始终拿不到 IP** 也会自动退出，避免无网状态下无限等待、屏幕常亮空耗电。计时只在「未联网」时累加，**联网立即清零**（「无网→联网→再断网」重新等满 2 分钟）。屏幕先显示英文 `Waiting for network...`，到点显示 `No network 2min, closing...` 后执行 `stop.sh`。**「从不」档位表示关闭自动退出，此超时同样不生效**；其余档位下无网超时独立生效，不受档位秒数影响。
- 想完全不自动退出：把档位设为「从不」即可。

## 语言切换 / Language

- **默认中文**：插件默认以中文显示，不判断 Kindle 系统语言，无需任何配置即可直接使用。
- **菜单内切换**：点菜单最后一项——当前为中文时显示 `English`、为英文时显示 `中文`（即"将要切换到的目标语言"本身的名字），进入后选 **中文** 或 **English** 即可。
- **手动切换（等效）**：在插件根目录（即 `extensions/filebrowser/`，与 `start.sh` 同级）新建名为 `LANG` 的文件，内容只写 `en`（英文）或 `zh`（中文）一行；保存后重启 KUAL 生效。删除该文件即恢复默认中文。
- 说明：`LANG` 文件仅含 `en` 或 `zh` 一行文本；eips 屏上状态提示因字体不含中文字形，始终为英文。

## 菜单结构 / Menu

```
网页文件管理器 2
├ 启动（飞行模式下先提示「打开网络并继续 / 暂不启动」）
├ 关闭（按需还原飞行模式，返回桌面）
├ 自动退出：01分 → 从不 / 01分 / 03分 / 05分   ← 全部为「连续无传输该时长即退出」
├ 更新核心程序（先校验，再选择 确认更新 / 暂不更新）
├ 本机IP: 192.168.x.x   ← 直接显示，点击可在屏幕显示 IP（eips 12,3）
└ English / 中文         ← 菜单最后一项：中文菜单显示 English，英文菜单显示 中文；点开可选 中文 / English
```

## 脚本结构 / Structure

所有脚本共享 `lib.sh`，避免重复代码：

| 脚本 | 职责 / Role |
|------|------|
| `lib.sh` | 公共函数库（IP 获取、屏幕状态、语言判断、短轮询 `nap()` 等） |
| `genmenu.sh` | 按设置/更新状态生成 `menu.json`（含中英文与版本号） |
| `start.sh` | 启动（飞行模式处理、常亮、开端口、显示 IP、脱离终端后台启动核心程序与自动退出守护；v2.0.6 起各段等待均为短轮询、菜单重建放后台、回桌面双写屏显） |
| `stop.sh` | 关闭 / 自动退出的唯一出口：结束服务与守护，按需还原飞行模式，返回桌面 |
| `ip.sh` | 屏幕显示本机 IP（位置见 `lib.sh` 的 `IP_ROW`/`IP_COL`） |
| `timeout.sh` | 设置「连续无传输 N 秒后退出」（写 `AUTOCLOSE`，先重建菜单确保一次点击即生效） |
| `idle.sh` | 自动退出守护：连续无传输达到档位时长、或连续 2 分钟无网络时调用 `stop.sh`；`AUTOCLOSE=0`(从不)时空转待命；另负责每 3 秒刷新本机 IP 屏显与联网门控 |
| `setlang.sh` | 设置界面语言（写 `LANG` 并刷新菜单），供语言选择菜单调用 |
| `update.sh` | `check`=校验更新；`do`=下载安装 |

## 说明 / Notes

- **核心程序启动方式**：filebrowser v2.63.23 是「无子命令直接启动服务器」，`start.sh` 用
  `./filebrowser --noauth -a 0.0.0.0 -p 80 -r /mnt/us -d ./filebrowser.db`（**不带 `serve`**）。
  早期版本误加了 `serve` 子命令，会报 `unknown command "serve"` 立即退出、80 端口无人监听，
  导致"启动成功（显示了 IP）却 `ERR_CONNECTION_REFUSED`"——已修复。
- 端口 80 已通过 `iptables` 放行（该规则同时兼作传输计数器，故只在不存在时插入一次）；后台以 `setsid` 完全脱离终端并将日志写入 `/tmp/filebrowser.log`，避免联网/断线时崩溃。启动前会先结束残留进程（释放 80 端口与数据库写锁），并清理上一轮的自动退出守护以免叠加。
- 启动后会以 0.2 秒粒度轮询 `/proc/net/tcp` 与 `/proc/net/tcp6` 等待端口监听（上限 12 秒、命中即走；`-a 0.0.0.0` 时监听落在 IPv6 双栈表）。
- **启动速度（v2.0.6）**：开网、清残留、等服务就绪均改为 0.2 秒粒度短轮询（条件满足立刻继续，老固件自动退化为 1 秒），菜单重建移到后台，回桌面后双写 eips；从点击「启动」到看见 IP 约 2 秒（旧版约 6~10 秒）。
- `eips` 帧缓冲字体不含中文字形，故屏上状态提示统一用英文；中文仅保留在 KUAL 菜单 UI。
- `AUTOCLOSE` 保存空闲退出秒数（`0`=从不、菜单提供 从不/1分/3分/5分 四档）；旧值仍按分钟换算显示。`WIFI_STATE` 为运行时临时状态，请勿手动编辑。
- **无网络超时可调**：`idle.sh` 顶部的 `OFFLINE_MAX`（默认 120 秒 / 2 分钟）控制无网退出时长，设为 `0` 即禁用；档位选「从不」时该超时同样不生效。
- 修改 IP 显示位置：编辑 `lib.sh` 顶部的 `IP_ROW` / `IP_COL`（默认 12 / 3）。
- 升级核心版本后启动失败：可删除 `filebrowser.db` 重新「启动」，filebrowser 会自动重建配置。
- **无法访问排查**：浏览器务必用 `http://<IP>:80`（不要写 `https://`）；启动脚本已先完成端口就绪检测才显示 IP，看到 IP 时服务即已监听；若仍连不上，启动后屏幕会显示 `Err: …`（取自 `/tmp/filebrowser.log`），常见原因：① 本题 Kindle 架构与 `filebrowser`(armv7) 不符导致无法执行；② 防火墙/网络不在同一网段；③ 端口被其它程序占用。

## 相关项目：KOReader 快捷方式插件（推荐）

如果你也用 **KOReader** 看书，推荐搭配使用本项目的 **KOReader 快捷方式插件 `kofb.koplugin`**：

- 仓库地址：<https://github.com/Gh9518/kofb.koplugin>
- 作用：在 KOReader 内**一键启动 / 关闭**「网页文件管理器 2」，**不用退出 KOReader** 即可通过浏览器无线传书、管理文件；IP 直接显示在菜单「启动」右侧。
- 特点：**不另装一套 filebrowser**——它只是本扩展包的快捷方式，直接复用这里已内置的核心程序，因此额外占用极小、且随本扩展包升级而自动适配。
- 依赖前提：需先安装本 KUAL 扩展包「网页文件管理器 2」并让核心程序就位（详见该插件仓库说明）。

> 适合想在 KOReader 前台一边看书、一边随时传文件的场景。
